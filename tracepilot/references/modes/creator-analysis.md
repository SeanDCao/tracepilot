# 博主发现、画像与匹配

从合作目标开始：需要解释复杂功能、触达某类人群、建立信任，还是形成可测试的销售内容？候选发现与合作推荐是两步，不能只按粉丝数排序。

- 通常由产品/品类/特征找到相关内容，再取稳定作者 ID、账号资料和多条近期作品。显示名、handle、URL 与平台标准 ID 分开；同名跨平台账号不自动合并。
- 逐位评估内容相关性、风格、活跃、可见表现、受众证据和合作冲突。风格至少看多条作品；只有明确受众字段才能说粉丝画像，账号所在地不等于粉丝所在地。
- 标明品牌自有内容、广告、联盟链接与历史合作；与目标品类相关并不自动意味着合作有效。缺报价、受众或转化数据时给适合进一步接洽的候选，而不预测 ROI。
- 面向合作人员展示可打开的账号及代表作品、匹配理由、风险和建议 brief；内部保存筛选掉的人及依据。

各平台稳定 ID 和可取内容的路径见[创作者取数窍门](../sources/realtrace/creator-ids.md)。
