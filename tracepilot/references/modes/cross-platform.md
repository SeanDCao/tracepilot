# 跨平台综合

跨平台研究围绕同一个研究问题组合证据，不是拼接平台报告。先确定各平台各自能回答什么，再选择可以对齐的对象、话题、人群经验或内容表达；问题可以是格局梳理、解释、机会探索或决策，不必预设商业立项。

- 平台内保留独立查询、时间、选择规则、分析单位和分母。跨平台同名商品、账号或话题建立显式映射；无法核对时只做并列观察。
- 先比较一致、差异和冲突，再解释可能原因。Amazon 商品评论、Reddit 社区提问与 TikTok 推广视频是不同语境；出现同一词不等于同一需求强度。
- 关键跨平台判断须有至少两个不同平台的合格来源支持，并看反例。只有单平台支持时按该平台写；某个承诺的场域无效时先补证，否则降低综合结论。
- 若任务要求商业动作，应连起链路，例如评论痛点 → 社区语言 → 内容表达 → 可测试的 Listing 或传播实验。任何一环缺成本、受众或转化数据时写成待验证假设。探索型报告先综合平台之间如何互相解释或互相矛盾，不以动作清单代替发现。

报告结构随问题而定，可以把最关键的商品、观点和内容放在同一比较中，但不要制造跨平台总分或总热度。
