# RealTrace · YouTube

**适用**：视频搜索、评论、频道发现。**状态**：2026-09-17 的 `keyword`＋单平台 `platforms` 对象、`video` 类型、`relevance` 排序，以及从视频 `channel_id` 回查频道或近期作品有有界真实样本；其他参数组合未由该样本验证。

搜索命中只说明标题或摘要与查询相关。要分析论点，取视频详情或字幕；若详情不可达，标题或概要最多按[公开检索规则](../public-web.md)说明公开结果出现了某种表述，不能还原完整论点。没取得画面不评价演示和剪辑。评论用前序视频返回的正式 `target_id`，保留父视频和评论链接。频道 `country` 不等于粉丝地区；账号风格看多条作品，受众判断需明确受众字段。联盟链接与返利应标成商业内容，不能把其互动解释为自然需求。

如果当次搜索结果缺 views/likes，不填零，也不与其他平台互动比较。按实时指南确认当前 ID、字段、分页及成本。
