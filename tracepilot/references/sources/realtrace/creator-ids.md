# RealTrace · 其他创作者 ID 路径

**适用**：按产品或内容发现账号，再获取资料与近期内容。**状态**：2026-09-17 的 V14 指南记录以下平台 ID 语义；本项目仅 YouTube channel_id 路径有有界真实样本。始终以当前指南和前序真实响应核对。

| 平台 | 当时指南中的关键 ID／限制 |
| --- | --- |
| YouTube | channel_id；频道所在地不等于粉丝地区 |
| TikTok | 数字 user_id 用于资料，sec_uid 用于账号内容 |
| Facebook | 账号内容用数字 owner/page ID，核对主页 URL |
| Instagram | 帖子详情的 media_id/comment_target_id 才是评论入口 |
| LinkedIn | /in/ 用户名与匹配完整 URL |
| X | 机器平台码 twitter，数字 Rest ID |
| Reddit | 可取作者资料；当时未提供账号内容工具 |

显示名、handle、主页 URL 和标准 ID 分开记录；跨平台同名不自动认定为同一人。未取得明确受众字段时，不能从内容风格或账号所在地推断粉丝年龄、地区、购买力。
