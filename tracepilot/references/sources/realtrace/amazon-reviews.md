# RealTrace · Amazon 商品评论

**适用**：Amazon 指定商品的正文评论。**状态**：普通评论与后台取数路径曾有 2026-09-17 有界真实样本；精确星级参数见当时 V14 指南，服务端筛选效果及“全量”尚未端到端验证。所有数字和参数以当前指南和 `schema` 为准。

先从用户有效输入或商品搜索、详情取得标准 `ASIN` 和站点，保持 `domain_name` 一致。少量样本使用当前普通请求可支持的单场景，不因存在分星级策略就发五次请求；更大目标按实时契约考虑持久任务，单次目标不是商品评论总量。

用户明确要“尽可能全量”时，当前上游 V1 指南需将 1–5 星各作为精确星级场景（`min_rating=max_rating=N`），其他筛选与排序保持一致。每支分别保存参数指纹、任务 ID、游标、返回与停止原因；默认顺序执行，先检查任务容量。不能跨星级复用 `cursor` 或 `task_id`，不能把 5 × 服务上限当默认预算。若实时契约改变，重新验证而不照搬本段参数。

合并时保留原始批次和星级来源关系，按稳定评论 ID 去重；无 ID 不凭短文本武断合并。核查每条实际星级，不能仅依查询条件赋星。`global ratings` 与带正文评论分开。上游自然耗尽、目标达到、服务上限、结果读取完成是不同状态；最多称“当前工具在这些查询场景的可达并集”，不能保证 Amazon 全部历史评论。

**质量防线**：2026-09-17 的三个 Amazon US 样本中评论日期显示 1970 占位，且无单条可核对 URL。这是当次来源异常，不是平台常态；遇到占位日期置为未知，禁做近期占比。无直链不能伪造，必要时从公开商品页核对版本/评论；无法核对的单条原文不应独立承担关键结论。
