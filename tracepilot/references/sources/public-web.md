# 公开资料取数

公开检索与 RealTrace、用户资料及其他可用来源并行规划，不受已接入 MCP 平台清单限制。根据问题主动寻找能直接回答它的原始记录、官方文件、统计、研究、技术资料、当事方发布、独立调查或可靠报道；宏观指标、行业报告、受众背景、社会事件、政策法规、论文和价格说明只是例子。优先匹配对象、地域和时间的权威原始资料，再用独立来源核对重要或有争议的事实。

检索结果分层使用：可访问原文或原始数据可以在核对口径后承担相应主张；可靠二手资料只承担其实际报道或分析；搜索标题、列表概要和截断摘要默认用于发现。若详情不可达，先寻找同一材料的可访问版本、其他权威原始来源或可靠二手来源；仍不足时，标题或概要才可作为**受限弱证据**，仅说明“检索结果中出现了某种公开表述或讨论线索”。记录结果 URL、显示标题、来源域名、查询与读取时间，并明确没有核对原文。

弱证据不得当作完整观点或逐字引文，不承担精确数字、定义、适用条件、比例、因果、普遍性、对象详情或关键决策结论；多个结果重复同一标题也不会自动升级为已验证事实。尽量用独立可访问来源交叉核验；无法核验时在成品中降低表述并标为线索或未解决，不以标题推断正文未显示的内容。电商与社媒任务仍须遵守专项规则：搜索列表不能替代商品详情、帖子正文、字幕、画面、评论或稳定对象 ID。

为关键公开事实在当前任务目录内部保留 URL、标题、发布及读取时间、对象、地域、时期、定义、单位、分母、版本和支持的原文位置。不同层级、指标和证据单位不能互换；事件发生时间与报道发布时间分开。来源方的功能或效果声明仍是来源方声明，研究只验证其实际测量的对象与条件，制度结论以适用地域与现行原文为准。背景资料只能提供背景或约束，不能替代研究对象的直接证据。

补证时核对来源身份、对象、标题、版本与页面链接是否一致；涉及平台内容时继续核对原生 ID 和父对象。不为缺直链编造 URL。补证失败，说明哪个判断仍不能成立。成品只在相应对象、统计或主张旁放必要链接，不追加整个公开来源台账。
